# 汤薇tamy 主页封面视觉公式

观察来源：[小红书主页](https://www.xiaohongshu.com/user/profile/5af90406e8ac2b0b051c88c1)；由用户给的[示例笔记](https://www.xiaohongshu.com/explore/6af9bcb1000000002203ae98)进入。2026-11-18 观察连续约 30 张可见封面。封面随发布更新，以下是样本规律，不是固定模板。

## 一句话公式

**清晰的改造后人物大图 + 改造前或过程的小图证据 + 一句占据画面边缘的大号结果标题 + 一两个具体人群/问题标签。**

主次参考：改造后人物约占视觉注意力的 60%，对比证据约 25%，标题与标签约 15%。这些是视觉权重，不是严格面积配额。

## 版式

- 3:4 竖图。人物常占画面高度大半，发型完整、脸部清楚。背景多保留沙龙或生活现场，而非纯色商业海报。
- 常见布局 A：改造后大图为底；改造前小图贴在右侧或下角；发型师或过程小图再加一层；主标题横跨底部。
- 当用户提供 before、after、发型师与客人合影这组三张图时，采用左右清晰分区的人物抠图版：after 大人像占左侧，右侧上方放发型师与客人双人抠图、下方放 before 人物；右侧人物不要过小，可用细白边凸显轮廓。背景两侧用连续渐变衔接，不使用硬色块拼缝、矩形照片框，也不把标签压在人头上。
- 常见布局 B：两到三张大人像上下或左右拼贴，突出同一个人的改造前后；主标题放上沿或下沿。
- 人物与标题可轻度叠压，但标题不能盖住发型轮廓与眼睛。小图可以不规则裁切，保留真实现场感。
- 不是每张都有完整的“前后对照”。一张结果照足够强时，可用单人大图和一行大字；也有少量弱文字封面。

## 字体与颜色

- 主标题通常是极粗黑体或等效中文粗体，一到两行；字形紧凑，手机缩略图下也能读清。
- 高频主色是淡奶黄、亮黄和白色。常用深棕或黑色粗描边，再加短距离深色阴影，让文字压在复杂照片上仍清晰。
- 标签更小，常用黄底黑字、白字黑边，或斜放的短语。不要让标签与大标题争夺层级。
- 彩色主要来自人物发色、衣服和现场照片；整张图不需要统一成单一滤镜。保持脸与发色真实。

## 标题与信息钩子

图内标题多比笔记标题更短，直接命名造型或变化，例如“王菲感短发”“东方韵味头”“微胖美式发型”“黄黑皮挑染”“古早千金头”。有时是结论或转折，如“短发劝退”“该换发型了”。

可从以下结构里选最贴合真实内容的一种：

1. **人群/脸型 + 发型**：方圆脸短发、黄黑皮挑染。
2. **风格结果 + 发型**：装姐感短发、古早千金头。
3. **改造判断/转折**：该换发型了、短发劝退。
4. **情绪或身份 + 第一次尝试**：毕业后第一次漂发。

小标签再补“改造前”“方圆脸”“显幼态”等具体信息。标题不夸大到照片无法证明的效果；不要对人物身材、肤色或脸型加入用户未提供且不必要的负面判断。

## 制作判断

- 优先选改造后最能展示发型弧线、发色和面部气质的照片，而非只看表情。
- 两张照片光线差异大时，做适度白平衡与曝光统一，同时保留前后差异。
- 标题遮挡人脸时，换位置或降低字数；不要单纯缩小到不可读。
- 在左右分区的三人拼贴中，检查右下是否出现大块空白；可将右下的 before 人物等比放大并下移，让衣服与发丝自然填入底部。始终保持抠图的原始宽高比。
- 在手机信息流尺寸查看：先看到“变美后的谁”，再读到“变成什么发型”，最后才发现“原来如何”。
