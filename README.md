# 小红书发型改造封面 Skill

输入改造前、改造后及发型师与客人的合影照片，制作 3:4 小红书竖版发型改造封面。设计规则归纳自 [汤薇tamy 的小红书主页](https://www.xiaohongshu.com/user/profile/5af90406e8ac2b0b051c88c1)；本仓库不包含该账号的照片或封面，也不包含客户照片和本次制作的成品。

## 使用

将仓库内容放入 Codex 的 `~/.codex/skills/xiaohongshu-hair-makeover-cover/`，然后在 Codex 中说：

> 用 `$xiaohongshu-hair-makeover-cover`，根据这三张 before、after、发型师合影照片做小红书封面。主题是……

手机使用时，可在 ChatGPT App 的 Remote 中连接安装了此 skill 的电脑，上传照片并发出同样的请求。GitHub 仓库本身不会自动把 skill 安装到手机。

详细制作要求见 [SKILL.md](SKILL.md)，封面公式见 [references/cover-formula.md](references/cover-formula.md)。
